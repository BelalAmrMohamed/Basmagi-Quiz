# MATLAB language essentials

This lesson introduces `switch` selection, cell arrays, structure fields, and grayscale histogram equalization with `histeq`.

MLWeb implements an educational MATLAB-style subset; these examples run in the browser without a MATLAB installation.

## Equalize image contrast

`histeq` accepts a two-dimensional grayscale image and returns an output of the same class and size.
%% code
I = imread('testgray.png');
J = histeq(I);
size(J)
imshow(J)
