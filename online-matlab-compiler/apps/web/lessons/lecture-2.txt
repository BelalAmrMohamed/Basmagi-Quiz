# Lecture 2 · Image representation
**Image types:** Binary · Grayscale · Color-24 (RGB) · Color-8 (indexed, with a *lookup table*).

An **indexed** image stores one number per pixel. That number is a row of a color table (the *map*), with one RGB triple per row.

## The same code as a script
Only the green layer of the top-left 200×200 block changes, so the picture gets greener.
%% code
a = imread('test.png');
imtool(a);
for i = 1 : 200
    for j = 1 : 200
        a(i,j,2) = a(i,j,2) + 50;
    end
end
imtool(a);

## The same code as a function
`brightcolor_v1` adds the same value V to all layers; `brightcolor_v2` adds a different value to each layer.
%% code
function brightcolor_v1(imgname, V)
    c = imread(imgname);
    imtool(c);
    for i=1:size(c,1)
        for j=1:size(c,2)
            c(i,j,1) = c(i,j,1) + V;
            c(i,j,2) = c(i,j,2) + V;
            c(i,j,3) = c(i,j,3) + V;
        end
    end
    imtool(c);
end
%% code
function brightcolor_v2(imgname, R, G, B)
    c = imread(imgname);
    imtool(c);
    for i=1:size(c,1)
        for j=1:size(c,2)
            c(i,j,1) = c(i,j,1) + R;
            c(i,j,2) = c(i,j,2) + G;
            c(i,j,3) = c(i,j,3) + B;
        end
    end
    imtool(c);
end
%% code
brightcolor_v1('test.png', 50);
%% code
brightcolor_v2('test.png', 150, -150, -150);
