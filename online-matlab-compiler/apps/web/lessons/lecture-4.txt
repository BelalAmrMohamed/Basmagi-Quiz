# Lecture 4 · Color spaces, cropping and gray conversion
## HSV
`rgb2hsv` gives `H` (hue), `S` (saturation), `V` (value = brightness), all from 0 to 1.
%% code
a = imread('pepper.png');
imtool(a);
b = rgb2hsv(a);
H = b(:,:,1);
S = b(:,:,2);
V = b(:,:,3);
imtool(b), imtool(H), imtool(S), imtool(V);
%% md
## YCbCr
`Y` is the brightness; `Cb` and `Cr` are the blue and red color differences.
%% code
a = imread('pepper.png');
c = rgb2ycbcr(a);
Y  = c(:,:,1);
Cb = c(:,:,2);
Cr = c(:,:,3);
imtool(c), imtool(Y), imtool(Cb), imtool(Cr);
%% md
## YIQ
%% code
a = imread('pepper.png');
d = rgb2ntsc(a);
Y = d(:,:,1);
I = d(:,:,2);
Q = d(:,:,3);
imtool(d), imtool(Y), imtool(I), imtool(Q);

## Cropping (50 rows × 100 columns, starting at pixel (61,61))
Copy pixel by pixel. `r` and `c` walk through the source image.
%% code
a = imread('pepper.png');
b = zeros(50,100,3,'uint8');
r = 61;
c = 61;
for i=1:size(b,1)
    c = 61;
    for j=1:size(b,2)
        b(i,j,1:3) = a(r,c,1:3);
        c = c+1;
    end
    r = r+1;
end
imtool(a), imtool(b);
%% md
**Another way** with ranges, pixels (61,61) to (110,110):
%% code
a = imread('pepper.png');
b2(1:50,1:50,1:3) = a(61:110,61:110,1:3);
imtool(a), imtool(b2);
%% md
## Color to grayscale
**Method 1: take one layer.** Each layer of a color image is itself a gray image.
%% code
a = imread('pepper.png');
imtool(a);
imtool(a(:,:,1));
imtool(a(:,:,2));
imtool(a(:,:,3));
%% md
**Method 2: average.** Look carefully at the two versions. In the first one `a(i,j,1)+a(i,j,2)+a(i,j,3)` is `uint8`, so the sum **saturates at 255 before** the division. The second divides first.
%% code
a = imread('pepper.png');
b1 = zeros(200,200,'uint8');
for i=1:size(a,1)
    for j=1:size(a,2)
        b1(i,j) = (a(i,j,1)+a(i,j,2)+a(i,j,3))/3;
    end
end
imtool(a), imtool(b1);
%% code
b1 = zeros(200,200,'uint8');
for i=1:size(a,1)
    for j=1:size(a,2)
        b1(i,j) = a(i,j,1)/3+a(i,j,2)/3+a(i,j,3)/3;
    end
end
imtool(a), imtool(b1);
