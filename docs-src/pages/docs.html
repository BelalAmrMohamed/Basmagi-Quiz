الأدلة والمساعدة

اختر الدليل المناسب لك لبدء المذاكرة، أو إنشاء المحتوى، أو إدارة المنصة، أو ربط الذكاء الاصطناعي بمساعدك المفضل.

آخر تحديث: 23 نوفمبر 2026 • 4 أدلة شاملة

طلاب

أدلة عملية لمساعدتك على المذاكرة الفعالة وشرح الأسئلة الصعبة

  • للمذاكرة الذاتية
    إنشاء امتحان للمذاكرة اصنع امتحانك الخاص من مذكراتك، ثم راجع أسئلته وعدّلها للتدرب قبل الامتحان الحقيقي.
    فتح الدليل
  • مساعد ذكي
    الباشــمبصمج مساعد ذكي داخل المنصة يشرح لك الأسئلة خطوة بخطوة ويساعدك في التحضير للامتحانات.
    فتح الدليل

صنّاع المحتوى

أدوات إعداد الامتحانات والمقررات التعليمية وتهيئتها للطلاب

  • إعداد الامتحانات
    إنشاء المحتوى أنشئ امتحاناً بالذكاء الاصطناعي أو يدوياً، ثم راجعه وعدّله قبل مشاركته مع الآخرين.
    فتح الدليل

مشرفون

إدارة المحتوى المعتمد وتدقيق الامتحانات والمواد المنشورة عاماً

  • للمشرفين فقط
    رفع المحتوى ونشره رفع الامتحانات وإنشاء المواد الدراسية والتحقق من نشرها في دليل المنصة العام.
    فتح الدليل

ربط الذكاء الاصطناعي

ربط منصة بصمجي ببروتوكول MCP مع Claude و ChatGPT و Gemini

  • بروتوكول MCP • فيديو
    ربط Claude / ChatGPT (MCP) اربط المنصة بمساعدك المفضل وأنشئ امتحاناً أو درساً أو دفتراً من محاضراتك، ليُحفظ مباشرة في «محتواي».
