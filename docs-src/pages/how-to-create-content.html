١. ما هو المحتوى المتاح على المنصة؟ نظرة عامة

تضم المنصة نوعين رئيسيين من العناصر لتغطية الاحتياجات التعليمية والتنظيمية:

  • الأنواع الأساسية الثلاثة:
    • الامتحان (Quiz): اختبار تفاعلي يدعم أسئلة الاختيار من متعدد، صح وخطأ، أكمل الفراغات، والأسئلة المقالية المصححة آلياً.
    • الدرس (Lesson): محتوى غني يدعم نصوص Markdown، وصيغ الرياضيات اللاتكس (LaTeX Math)، وتضمين فيديوهات يوتيوب، وربط امتحانات ودروس ودفاتر تقييمية بنهاية الدرس.
    • الدفتر البرمجي (Jupyter Notebook): بيئة برمجية تفاعلية تعمل داخل المتصفح للتدرب على لغة C++ ومادة معالجة الصور الرقمية بلغة MATLAB.
  • الأنواع التنظيمية والتكميلية الأربعة:
    • المواد (Courses): الحاوية الرئيسية في المستوى الأعلى لجمع كافة متطلبات المقرر.
    • المجلدات (Folders): أدوات هيكلة شجرية لتنظيم المحاضرات والأقسام الفرعية.
    • فيديوهات يوتيوب (YouTube Videos): تضمين شروحات الفيديو الفردية.
    • قوائم تشغيل يوتيوب (YouTube Playlists): إضافة قوائم تشغيل كاملة كبطاقة موحدة داخل المادة أو المجلد.

٢. الطريقة الأولى: الإنشاء اليدوي تحكم تفصيلي

تتيح صفحات الإنشاء المخصصة في بصمجي تجربة سهلة تشبه نماذج Google Forms لإعداد كل عنصر يدparamètres:

  • محرر الامتحانات (إنشاء امتحان): كتابة العنوان والوصف والمصدر، مع إمكانية ضبط التوقيت والدرجات. يدعم المحرر:
    • أسئلة الاختيار من متعدد وصح/خطأ: تحديد الإجابة الصحيحة وإضافة توضيح تعليمي لكل خيار.
    • أسئلة أكمل الفراغات: كتابة البدائل المقبولة داخل أقواس معقوفة مزدوجة مثل {{الخيار الأول|الخيار الثاني}}؛ حيث تظهر للطالب كخانة إدخال وتُحتسب إجابته صحيحة إذا طابقت أي خيار.
    • الأسئلة المقالية: يكتب الطالب إجابته ويقوم المصحح الآلي بمقارنة درجة التشابه والكلمات المفتاحية بين إجابة الطالب ونموذج الإجابة بدقة.
  • محرر الدروس (إنشاء درس): يدعم التنسيق الغني عبر Markdown (عناوين، نصوص عريضة ومائلة، قوائم وجداول)، وتنسيق المعادلات الرياضية عبر مكتبة KaTeX (LaTeX Math). كما يتيح تضمين فيديوهات يوتيوب بمجرد لصق رابط الفيديو، وإدراج عناصر مرتبطة (مثل امتحان تدريبي في نهاية الدرس ليحله الطالب فور انتهائه من القراءة).
  • محرر الدفاتر البرمجية (إنشاء دفتر): دفتر تفاعلي شبيه بـ Jupyter Notebook يعمل أونلاين بالكامل، يدعم C++ ومحاكي MATLAB المكتوب بلغة TypeScript، ويشمل ميزات التلميحات البرمجية (Code Suggestions) ومكتبة صور مدمجة للتدريب على معالجة الصور الرقمية.

٣. الطريقة الثانية: نسخ الأوامر الجاهزة (Prompt Templates) نماذج خارجية

إذا أردت استخدام نماذج ذكاء اصطناعي خارجية متقدمة (مثل Gemini أو ChatGPT أو Claude) لتوليد الأسئلة والدروس من محاضراتك:

  1. افتح نافذة الإنشاء على المنصة، واضغط على خيار الحصول على الأمر المساعد (Prompt).
  2. انسخ نص الـ Prompt المخصص الذي يحدد معايير وهيكل بيانات بصمجي.
  3. توجه إلى نموذج الذكاء الاصطناعي المفضل لديك، وارفع ملف المحاضرة (PDF أو مستند نصي) مع لصق الـ Prompt.
  4. سيقوم النموذج بتوليد المحتوى المطلوب بصيغة JSON قياسية مهيأة للمنصة.
  5. انسخ كود الـ JSON الناتج، وعد إلى المنصة والصقه في حقل الاستيراد ثم اضغط «إنشاء» ليظهر العنصر في محتواك فوراً.
  6. في حال نبهتك المنصة لوجود خطأ في تنسيق الـ JSON، يمكنك نسخ رسالة الخطأ للنموذج ليعيد تصحيحها في ثوانٍ.

٤. الطريقة الثالثة: المساعد الذكي المدمج (الباشــمبصمج) توليد فوري ومباشر

تعد هذه الطريقة الأسهل والأسرع، حيث تتيح لك إنجاز كل شيء بضغطة زر داخل المنصة دون نسخ ولصق:

  • افتح نافذة المساعد الذكي «الباشــمبصمج» من الواجهة.
  • ارفع ملف محاضرتك واطلب منه الأمر باللغة الطبيعية، مثل: «لخص هذه المحاضرة في درس تعليمي تفاعلي» أو «أنشئ امتحاناً شاملاً من هذا الملف».
  • يقوم المساعد بتحليل الملف وتوليد الدرس أو الامتحان أو الدفتر وإضافته مباشرة إلى «محتواي» لتجده جاهزاً للمعاينة والتعديل.
  • يعمل المساعد افتراضياً ومجاناً بنموذج Gemini Flash Lite، كما يتيح لك تبويب الإعدادات حفظ مفتاح API خاص بك لاستخدام نماذج أخرى مثل Claude أو DeepSeek بدون حدود.

٥. الطريقة الرابعة: الربط عبر خادم الـ MCP Server تكامل تلقائي

للمستخدمين المعتمدين على أدوات سطح المكتب (مثل Claude Desktop):

يمكنك ربط تطبيق Claude بخادم الـ MCP التابع لمنصة بصمجي مرة واحدة. يتيح لك ذلك رفع ملفاتك إلى المساعد والطلب منه إنشاء المحتوى ليقوم المساعد بإنشائه على خوادم بصمجي تلقائياً وتزويدك برابط مباشر لحفظه في «محتواي» دون أي تدخل يدوي أو نسخ كود.

للاطلاع على الخطوات المصورة لربط الـ MCP وتحميل الـ Skill، توجه إلى دليل ربط Claude و ChatGPT (MCP).

٦. أنواع المحتوى والروابط المباشرة مرجع الأنواع

تدعم المنصة ستة أنواع من عناصر المحتوى، لكل نوع منها مسار مخصص وأقسام ثابتة يمكنك الانتقال إليها برابط مباشر:

المواد الدراسية (Courses)

المادة هي الحاوية العليا لمقرر دراسي كامل، وتظهر في المستوى الرئيسي للمنصة لتجمع امتحانات المادة ودروسها ودفاترها ومجلداتها، ولا يمكن وضع مادة داخل مجلد.

المجلدات (Folders)

تستخدم المجلدات لتنظيم وتقسيم محتوى المادة إلى فصول ومحاضرات، ويمكن إنشاء مجلدات فرعية متداخلة بداخلها بكل سهولة عبر النقر بزر الفأرة الأيمن أو زر الإنشاء.

الامتحانات التفاعلية (Quizzes)

إنشاء اختبار متكامل بأسئلة الاختيار من متعدد، وصح وخطأ، وأكمل الفراغات، والأسئلة المقالية مع تصحيح فوري وشرح تعليمي لكل سؤال ومراجعة دقيقة لخيارات الإجابة.

الدروس التعليمية (Lessons)

صفحة درس تفاعلية غنية بالأقسام وتنسيق Markdown ومعادلات LaTeX الرياضية وفيديوهات يوتيوب المضمنة، مع إمكانية ربط امتحانات تقييمية بنهايتها لحلها فوراً.

الدفاتر البرمجية (Notebooks)

بيئة تفاعلية شبيهة بـ Jupyter Notebook تعمل داخل المتصفح لتشغيل أكواد C++ ومحاكاة MATLAB لمعالجة الصور الرقمية مع ميزات الإكمال التلقائي وتوفر صور تدريبية مسبقة.

فيديوهات وقوائم تشغيل YouTube

إضافة فيديو يوتيوب فردي بالبحث أو لصق الرابط، أو إدراج قائمة تشغيل (Playlist) كاملة كبطاقة موحدة داخل محتواك، مع إمكانية طلب البحث عن الفيديوهات عبر الباشــمبصمج مباشرة.
